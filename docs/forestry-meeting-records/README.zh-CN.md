# 使用林地会议记录

[Skills 总目录](../../README.zh-CN.md) | [English](README.md)

依据指定的林木权属证明制作会议记录底稿，永久、临时分开，村级和林场分别采用相应格式，会议事实留空供实际会议填写。

## 环境与安装

通过 CC Switch 安装 `forestry-meeting-records`，或完整复制对应 Skill 文件夹，保留 `assets/`、`references/` 和 `agents/`。安装方式见 [仓库首页](../../README.zh-CN.md)。

本 Skill 没有固定脚本入口，不要求新增 Python 包；使用执行环境已有的文档编辑和渲染工具。具备 Microsoft Word 时，用独立实例重开、核对分页并导出预览；其他环境使用已有且适用的渲染能力。

## 准备资料

- 提供明确版本的林木权属证明、项目根目录和永久／临时性质，不自动转用调查表或旧版证明。
- 核实会议主体为村级还是林场，工程名称、建设单位、地点、地块编号及面积均沿用指定来源。面积保留来源精度，编号保留前导零和非连续关系。
- 需要更新已有记录时，明确更新范围；已填写的会议事实、人工文字和签章不能直接用模板覆盖。

## 使用

向 Agent 提出：“使用 $forestry-meeting-records，根据这些临时林木权属证明制作村级和林场会议记录底稿。”同时提供证明路径及项目目录。

Agent 核对来源后，使用 [内置模板](../../skills/forestry-meeting-records/assets/meeting-record-template.docx) 制作候选。时间、会议地点、主持人、记录人和人数留空；正文仅预填讨论事项，不自动写表决结果或会议决定，不增加权属结论。

## 输出与核对

默认保存到 `项目根目录/06_公示查验与报批/永久或临时/会议记录/`。村级按项目和使用性质合并为 `会议记录（永久）.docx` 或 `会议记录（临时）.docx`，各村独立起页；林场默认每处一份 `会议记录（林场全称）.docx`。

逐份核对来源和全部页面，检查名称、编号、面积、留白、签字空间和落款；默认每份记录一页。超长内容无法保持可读的一页时需确认续页。核对通过后只交付最终 DOCX，提取信息、备份和预览留在系统临时目录。

写入前再次检查来源和待更新文件是否变化。底稿仍需依据实际会议填写并现场签章，生成完成不代表会议已召开或已满足报批条件。

## 更新与详细规则

通过原安装工具更新 Skill，不重建或覆盖项目内已完善的记录。执行边界见 [执行规则](../../skills/forestry-meeting-records/SKILL.md)，字段、文字和版式见 [会议记录规则](../../skills/forestry-meeting-records/references/meeting-record-rules.md)。
