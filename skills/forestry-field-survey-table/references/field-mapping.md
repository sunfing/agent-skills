# 原始因子与外业调查字段对应

原始因子表35列、外业调查表37列；不含项目旧编号。源表第一行为表头且从 A1 开始。额外 GIS 属性列忽略。

| 原始因子字段 | 源字段／处理 |
|---|---|
| 市、县、乡 | 同名字段；可用已确认的命令参数补充或覆盖 |
| 村 | ZLDWMC |
| 林班号、林地落界小班号 | LIN_BAN、XIAO_BAN；保留原始短编号，不拼造长编码 |
| 小班编号、面积 | 小班编、面积；可指定其他字段，面积须已确认为占用面积 hm² |
| 地类 | DLMC；灌木类名称统一为一般灌木林地，其他原名保留 |
| 林地类型 | 按林种归并，见下表；苗圃地直接填苗圃地 |
| 林地权属、森林类别、保护等级 | LD_QS、SEN_LIN_LB、BH_DJ |
| 林种、起源、重点生态区域 | LIN_ZHONG、QI_YUAN、STQWMC |
| 优势树种、龄组 | YOU_SHI_SZ、LING_ZU |
| 树高、胸径、郁闭度、每公顷蓄积 | PINGJUN_SG、PINGJUN_XJ、YU_BI_DU、MEI_GQ_XJ |
| 小班蓄积、经济（竹）林株数 | 留空，MEI_GQ_ZS 不是该列的株数 |
| 坡向、坡位、坡度 | PO_XIANG、PO_WEI、PO_DU（角度，不是坡级） |
| 土壤类型、土层厚度 | TU_RANG_LX 原代码、TU_CENG_HD 原数值 |
| 建设内容、工程类别、林龄 | 留空 |
| 使用林地性质 | `--use-nature`明确指定，否则留空 |
| 公益林事权 | SHI_QUAN_D：10国家公益林、20地方公益林；未知代码原样保留 |
| 备注 | 塔号原值 |

| 特用林／特种用途林 | 原名称 | 特用林林地 |

这是已确认模板的工作对应，不宣称为跨版本官方字典。林种保留细类，不将水源林、水保林显示成防护林；未知代码原样保留且林地类型留空。其他亚类须有明确映射后再加入，不按代码前缀猜测。

- 灌木林地、一般灌木林地、特殊灌木林地、国家特别规定灌木林地统一输出“一般灌木林地”；不改源数据，不再要求细分。
- 森林类别沿用SEN_LIN_LB，公益林事权沿用已定层级，不追加省市县细分；BH_DJ不替代公益林保护分级。
- 其余内置映射以脚本MAPS为准：权属10国有/20集体；森林类别012一般公益林/022一般商品林；保护等级3Ⅲ/4Ⅳ；起源11天然/21人工；龄组1幼龄林/4成熟林；树种200000油松、465000刺槐、490000其他硬阔类、590000其他软阔类、999000其他灌木；坡向1—9、坡位1—6按常用字典。土壤代码及未收录扩展码原样保留，不截尾。
- DI_LEI=030701不自动改为疏林地，仍采用DLMC并提示来源字典核对。

## 外业后交接

每公顷蓄积仅作源库参考，不反算覆盖核定小班蓄积；后续按核定值统计，仅计乔木林地，原精度求和后展示。其他区域经确认后对应重点生态区域“不涉及”，本脚本仍保留源名称。不得覆盖已人工完善的内业表；现状表、报告A.1及B.1—B.7由汇总Skill处理。

植被恢复费参考测算按材料选取地区标准：河北冀财税〔2016〕25号基准10/6/3元每平方米，另按公益林、规划区及建设性质调整。临时用林参考测算不写成应缴额（2023年第13号公告取消该项收费），实际恢复工程费用另计。本skill不计算费用。

完整代码、测算分类和来源见[Inkstone通用字典](https://ink.doro.you/n/01m4qhzmx6h1m47r4a7jvt48q8)。

## 独立外业记录

外业调查表同名成对栏的前列为原值、后列留空实测，不自动联动。范围包括地类、优势树种、树高、胸径、核定蓄积及地形土壤等。调查完成后人工核定到37列内业处理表；不得拿空白实测栏直接覆盖原值。郁闭度仅显示1位小数，存储精度不改。
