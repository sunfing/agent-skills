## 内置字典

完整可执行数据在 [code-dictionary.json](code-dictionary.json)，安装时必须一起携带。脚本读取同一文件，不维护另一份零散映射，不依赖个人笔记、账号或网络。

- 字典含15类字段、291个映射条目（含同义编码），其中林种24项、树种123项、土壤参考60项；这是已整理覆盖范围，不宣称覆盖全国全部版本及地方扩展。
- `codes`保存代码原义，`display`保存模板显示归并；林种的`land_types`逐码关联林地类型。每类记录`source`，242单独标明工作扩展来源。
- 权属21/22/23显示集体；起源11/12/13显示天然、21/22/23/24显示人工；龄组1—5及保护等级1—4完整收录。
- 森林类别11/12/21/22与011/012/021/022均明确收录，使用前核对源库口径；不全局去掉前导零。公益林事权10/20不反推省市县。
- 林种保留细类；111/112/233沿用水源林/水保林/用材林简称，其他条目使用已收录名称。251→果树林→经济林林地。标准名称和模板简称均可归并；未知林种保留，林地类型留空。
- 优势树种逐码匹配，例如706000→杏；410001、490006等扩展码不截尾套用410000、490000。
- 土壤参考表虽已内置，默认仍保留代码。确认源库与公开修订稿参考一致后，使用`--soil-dictionary revision-reference`启用；例如122→褐土。未收录代码仍保留。
- DI_MAO、坡度等级、G_CHENG_LB及审批项目类型收录为参考；当前表式无相应字段或须人工核定，不因此新增列或自动填工程类别。PO_DU角度不按坡度等级解码；林业工程与审批项目类型不混用。
- 灌木类按当前模板工作口径归一般灌木林地。DI_LEI、DLBM不跨版本猜释；仍采用DLMC，030701提示核对。

来源包含LY/T 1955—2011附录A（历史版，已被2022版替代）、公开修订稿参考、树种分类及代码表附8、模板工作口径与审批材料。来源说明及公开标准链接均随字典内置；树种图片完整版本尚待补充，土壤未以2022正式附录复核。默认采用当前工作字典；来源不符时先核对，不将本字典冒称最新统一标准。

执行结果`dictionary_coverage`逐字段区分已识别值、已收录但须确认的土壤代码、未收录值，以及只作参考的字段。发布前查看该结果；未知保留不是释义已完成。更新字典时同步脚本适用规则与相关测试。

## 外业后交接

每公顷蓄积仅作源库参考，不反算覆盖核定小班蓄积；后续按核定值统计，仅计乔木林地，原精度求和后展示。其他区域经确认后对应重点生态区域“不涉及”，本脚本仍保留源名称。不得覆盖已人工完善的内业表；现状表、报告A.1及B.1—B.7由汇总Skill处理。

植被恢复费参考测算按材料选取地区标准：河北冀财税〔2016〕25号基准10/6/3元每平方米，另按公益林、规划区及建设性质调整。临时用林参考测算不写成应缴额（2023年第13号公告取消该项收费），实际恢复工程费用另计。本skill不计算费用。

## 独立外业记录

外业表按以下顺序输出22列，不再保留成对树高、胸径、郁闭度或地形土壤栏；原始因子表仍保存完整参考数据。

| 列 | 字段 | 生成规则 |
|---|---|---|
| A—C | 小班编号、面积、原始地类 | 原始参考值 |
| D | 现状地类 | 留空 |
| E—I | 林地类型、林地权属、森林类别、林种、起源 | 原始参考值 |
| J | 原优势树种 | 原始参考值 |
| K | 优势树种 | 留空 |
| L | 龄组（产期） | 原始参考值 |
| M—S | 林龄、平均树高、郁闭度（覆盖度）、株数、坡向、坡位、坡度 | 留空 |
| T | 土壤类型 | 保留按字典规则处理后的原始参考值，未确认的代码仍保留 |
| U | 土层厚度 | 留空 |
| V | 备注 | 塔号原值 |

调查完成后人工结合原始因子表核定到37列内业处理表，外业表不直接作为报告输入。不得拿空白实测栏覆盖原值。郁闭度仅显示1位小数，存储精度不改。
