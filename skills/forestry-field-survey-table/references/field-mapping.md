# 最新模板字段对应

本 Skill 使用 `assets/A.1.xlsx` 作为唯一模板。永久、临时共用同一模板结构，由命令行参数 `--use-nature` 明确区分。输入字段默认使用标准名称 `序号`、`面积`；只忽略表头换行、连续空格和首尾空格，不把旧字段或 GIS 字段自动当作别名。

## 原始因子表（35 列）

| 模板列 | 标准字段名称 | 默认源字段／处理 |
|---|---|---|
| A—C | 市、县、乡 | 同名字段；可用已确认的 `--city`、`--county`、`--township` 补充或覆盖 |
| D | 村 | `ZLDWMC` |
| E | 林班号（村小组） | `LIN_BAN`，保留源值 |
| F | 小班号林地落界 | `XIAO_BAN`，保留源值 |
| G | 使用林地序号 | `序号`；保留文本编号和前导零 |
| H | 面积 hm2 | `面积`；必须已确认是占用面积，单位为 hm² |
| I | 原始地类 | `DLMC`；灌木类按模板工作口径统一为一般灌木林地 |
| J | 林地类型 | 按 `LIN_ZHONG` 映射；苗圃地直接填苗圃地，未匹配时留空并保留林种原值 |
| K—N | 林地权属、森林类别、公益林事权、林地保护等级 | `LD_QS`、`SEN_LIN_LB`、`SHI_QUAN_D`、`BH_DJ`；未知代码原样保留 |
| O—P | 林种、起源 | `LIN_ZHONG`、`QI_YUAN`；只做字典中已确认的转换 |
| Q | 重点生态区域 | `STQWMC`；源值为空则保持空白 |
| R | 原优势树种 | `YOU_SHI_SZ`；未知代码原样保留 |
| S | 龄组（产期） | `LING_ZU` |
| T—W | 林龄、平均树高 m、平均胸径 cm、郁闭度（覆盖度） | 模板参考字段；对应 `PINGJUN_SG`、`PINGJUN_XJ`、`YU_BI_DU` 等已确认源值 |
| X | 每公顷蓄积 m3 | `MEI_GQ_XJ`，仅作源库参考，不推算小班蓄积 |
| Y | 小班蓄积 m3 | 留空；不得由每公顷蓄积反算 |
| Z | 株数 | 留空；不得把 `MEI_GQ_ZS` 当作外业株数 |
| AA—AC | 坡向、坡位、坡度 | `PO_XIANG`、`PO_WEI`、`PO_DU`；坡度保留角度，不按坡度等级解码 |
| AD—AE | 土壤类型、土层厚度 cm | `TU_RANG_LX`、`TU_CENG_HD`；土壤名称只有在明确启用 `--soil-dictionary revision-reference` 且源版本已确认时转换 |
| AF—AG | 建设内容、工程类别 | 留空，需人工核定，不从目录名、代码或 GIS 属性推断 |
| AH | 使用林地性质 | 由必填参数 `--use-nature` 写入，只允许 `临时` 或 `永久` |
| AI | 备注 | `塔号` 原值；无值则空白 |

项目名称只在命令行显式提供 `--project-name` 时用于工作表标题；缺失时使用“建设项目”并发出 warning，不从目录名或文件名推断。

## 外业调查表（24 列）

外业表保留源值参考列，实测列统一留空，避免外业录入覆盖原始因子。列顺序严格按模板如下：

| 列 | 标准字段名称 | 生成规则 |
|---|---|---|
| A—C | 使用林地序号、面积 hm2、原始地类 | 原始参考值 |
| D | 现状地类 | 留空，外业填写 |
| E—F | 林地权属、原优势树种 | 原始参考值 |
| G—M | 优势树种、龄组（产期）、林龄、平均树高 m、平均胸径 cm、郁闭度（覆盖度）、株数 | 全部留空，外业填写 |
| N | 坡向（参考） | 原始参考值 |
| O | 坡向 | 留空，外业填写 |
| P | 坡位（参考） | 原始参考值 |
| Q | 坡位 | 留空，外业填写 |
| R | 坡度（参考） | 原始参考值 |
| S | 坡度 | 留空，外业填写 |
| T | 土壤类型（参考） | 原始参考值；未确认代码仍保留 |
| U | 土壤类型 | 留空，外业填写 |
| V | 土层厚度（参考） | 原始参考值 |
| W | 土层厚度 | 留空，外业填写 |
| X | 备注 | 塔号原值 |

外业表不包含原始因子表的林地类型、森林类别、公益林事权、保护等级、林种、起源和生态区域等列。后续调查完成后，人工结合原始因子表核定内业处理表；本 Skill 不把外业表直接作为报告输入。

## 字典和未确认值

完整字典位于 [code-dictionary.json](code-dictionary.json)，脚本运行时读取同一文件。未知代码原样保留并在 warning 中提示；已收录但需要源库版本确认的土壤代码单独进入 `dictionary_coverage.requires_source_confirmation`。字段不匹配、重复表头、面积语义未确认或编号语义未确认时停止，不自动迁移旧版字段。

每公顷蓄积是数据库参考值，不能用于反算或覆盖核定小班蓄积。公益林事权只按已确认代码转换，不从代码推断省、市、县层级。打印区域、分页、PDF 和打印预览不属于本 Skill 的验收范围。
