# A.1 字段对应

固定33列，不增列、不加工作表。源表第一行为表头且从 A1 开始。额外 GIS 属性列忽略。

| A.1 字段 | 源字段／处理 |
|---|---|
| 市、县、乡 | 同名字段；可用已确认的命令参数补充或覆盖 |
| 村 | ZLDWMC |
| 林班号、林地落界小班号 | LIN_BAN、XIAO_BAN；保留原始短编号，不拼造长编码 |
| 小班编号、面积 | 小班编、面积；可指定其他字段，面积须已确认为占用面积 hm² |
| 现状地类 | DLMC；DI_LEI 030701 的口径存在版本差异，仅在运行摘要提示 |
| 林地类型 | 留空 |
| 林地权属、森林类别、保护等级 | LD_QS、SEN_LIN_LB、BH_DJ |
| 林种、起源、重点生态区域 | LIN_ZHONG、QI_YUAN、STQWMC |
| 优势树种、龄组 | YOU_SHI_SZ、LING_ZU |
| 树高、胸径、郁闭度、每公顷蓄积 | PINGJUN_SG、PINGJUN_XJ、YU_BI_DU、MEI_GQ_XJ |
| 小班蓄积、经济（竹）林株数 | 留空，MEI_GQ_ZS 不是该列的株数 |

| 土壤类型、土层厚度 | TU_RANG_LX 原代码、TU_CENG_HD 原数值 |
| 建设内容、工程类别、使用林地性质 | 留空 |
| 备注 | 塔号原值 |

## 有限工作映射

这些映射记录已采用的整理口径，不宣称是跨版本官方字典。使用前应与项目属性库口径核对；其他代码保留，不截断扩展树种代码。映射的唯一执行定义在脚本 `MAPS` 中。

- LD_QS：10 国有，20 集体。不能拿 QSXZ 的另一套代码替换。
- SEN_LIN_LB：012 一般公益林，022 一般商品林。前导零需在源代码中保留。
- BH_DJ：3 Ⅲ，4 Ⅳ。
- LIN_ZHONG：111 水源林，112 水保林，233 用材林，242 能源林。242 的适用含义于2026-10-13经使用者确认，具体标准版本出处待补，不归称为2011版原表。采用细分林种简称，不能仅因模板示例出现“防护林”就自动合并分类层级。
- QI_YUAN：11 天然，21 人工。
- YOU_SHI_SZ：200000 油松，465000 刺槐，490000 其他硬阔类，590000 其他软阔类，999000 其他灌木。依据用户提供树种表确认的条目；不包含或发布该图片。
- LING_ZU：1 幼龄林，4 成熟林。其余未收录项保留代码，空白不推测。
- PO_XIANG：1 北、2 东北、3 东、4 东南、5 南、6 西南、7 西、8 西北、9 无坡向。
- PO_WEI：1 脊、2 上、3 中、4 下、5 谷、6 平地。
- TU_RANG_LX：未内置翻译；例如122保留原代码。

正式代码字典、版本差异、林地类型判定由业务资料解决，不由脚本补造。代码提示仅出现在运行摘要，不写入外调表。
