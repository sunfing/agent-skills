# 使用林地外业准备

使用内置 `assets/A.1.xlsx` 的两张表：35列“原始因子表”、22列“外业调查表”。模板不含项目旧编号。两表均为静态数据，不互相引用；外业填写不自动覆盖原始数据。名称仍为 A.1.xlsx 以保持安装资源路径兼容，工作表已不是旧版33列 A.1。

## 执行规则

- Windows、桌面 Microsoft Excel、Python 3.10+；无额外 Python 依赖。先读 [字段对应](references/field-mapping.md)。代码字典内置于 `references/code-dictionary.json`，脚本直接读取；安装后可独立使用，不需要个人笔记链接或账号。
- 确认源工作表、编号字段、占用面积字段及单位公顷。不得拿 TBMJ、XBMJ 或 Shape_Area 代替占用面积。市县乡须来自源表或已确认参数。
- “先讨论”时只读，不执行会创建暂存文件的命令。
- 保留编号及前导零；纯数字编号按数值排序，其余保留源顺序。缺失、重复编号和非法面积停止。
- 外业调查表只保留22列必要字段，具体顺序见字段对应。原始地类、原优势树种及土壤类型保留参考值；现状地类、优势树种、林龄、平均树高、郁闭度、株数、坡向、坡位、坡度、土层厚度留空实测。不得把原始参考值填入实测栏或自动回写内业表。
- 已知代码转换，未知代码原样保留，不添加“待核”。每公顷蓄积仅参考，不推算核定小班蓄积；公益林事权保留原数据层级，不推断省级、市县级。
- 使用性质仅在 `--use-nature` 明确指定时填写。核定蓄积、经济（竹）林株数、林龄、建设内容、工程类别留空。
- 两表默认按表头及数据自动列宽，排除合并标题。外业表固定列宽：现状地类、优势树种10，备注15；林龄、平均树高、株数、坡向、坡位、坡度、土壤类型、土层厚度3.5。标题行及数据行高20，其余行高自适应；原始因子表行高不变。保留字体、边框、数字格式及打印设置，不自动分页、不插入续页标题。数据区按记录数扩展，全表无背景填充；截图中的尺寸标注不写入成果。郁闭度显示1位小数，底层值不舍入。

## 运行

```powershell
python "<skill-root>/scripts/forestry_field_survey_table.py" "D:/项目/调查_初表.xls"
```

标题按“项目全称 使用林地性质 表名”生成，例如“某建设工程 永久使用林地 原始因子表”。生成前从用户信息或已核实的项目资料确定项目全称及临时/永久性质，通过 `--project-name` 和 `--use-nature` 传入；不从“永久”“表格”等目录名猜测项目名称。不明确时先询问；脚本兼容旧调用，未提供项目名时使用“建设项目”，未提供性质时仅写“使用林地”。

可选：`--project-name`、`--sheet`、`--id-field`、`--area-field`、`--city`、`--county`、`--township`、`--use-nature 临时|永久`、`--soil-dictionary revision-reference`（仅确认源库一致后启用土壤参考）、`--output`、`--check-only`。多工作表必须指定 `--sheet`；默认编号“小班编”、面积“面积”。`--check-only` 会使用 Excel 和临时文件，但不生成成果。

默认输出源文件同级目录，末尾 `_初表` 换成 `_外调.xlsx`；已有输出拒绝覆盖。脚本暂存、保存重开、逐格验证后发布，源文件不改动。

交付说明输出位置、记录数、占用面积及未解决代码。核对输出的 `dictionary_version` 和 `dictionary_coverage`，区分未知代码与已收录但尚未确认适用的土壤代码；不能把逐格验证通过说成全部释义完成。后续人工整理37列“内业处理表”（见汇总 Skill 模板）后，再运行 `forestry-survey-summary-tables` 生成现状调查表、A.1、B.1—B.7。旧版33列 A.1 不直接充当新内业输入。

更新安装时完整同步本 Skill 文件夹。不得用本工具覆盖已经人工完善的工作簿。
