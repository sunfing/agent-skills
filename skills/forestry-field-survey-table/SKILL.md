# 使用林地小班因子外调表整理

使用自带 `assets/A.1.xlsx`，无需用户提供模板。固定33列表式来自用户确认的“使用林地小班因子调查表.xlsx”A.1，已清空样例数据。只生成 A.1。

## 执行前

- 需要 Windows、桌面版 Microsoft Excel、Python 3.10+；无额外 Python 依赖。不满足环境时明确说明，不能改拼接 XML 来冒充正常 Excel 成果。
- 阅读 [字段对应和口径](references/field-mapping.md)。默认代码对应是有限工作映射，不是适用于所有地区、版本的通用国家代码字典。若来源口径不同，先确认，不套用。
- 确认源工作表、项目使用的编号字段、占用面积字段及面积单位为公顷。不得用原图斑面积 TBMJ/XBMJ 代替占用面积，或凭字段名推测单位。
- 市、县、乡名称来自源表或用户确认的参数，不根据工程名称、乡镇代码猜填。不同项目不复用上次的地名、16条记录或特例。
- 用户要求“先讨论”时只讨论，不运行写入或临时文件流程。

## 使用

```powershell
python "<skill-root>/scripts/forestry_field_survey_table.py" "D:/项目/使用林地小班因子调查表_初表.xls"
```

可选参数：`--sheet`、`--id-field`、`--area-field`、`--city`、`--county`、`--township`、`--output`、`--check-only`。

多工作表必须指定 `--sheet`，不猜“梳理”表是否存在。默认列名是“小班编”和“面积”。`--check-only` 只不生成成果，但会启动 Excel 并使用系统临时文件。

默认输出在源文件同级，把末尾 `_初表` 替换为 `_外调`，扩展名为 `.xlsx`。已有文件时拒绝覆盖；让用户明确处理方式，不自行删文件或改存到工作区。输出绝不覆盖源文件。

## 内容与格式

- 保留既有编号和前导零，不重新编号；编号全为数字时按数值排序，否则保留源顺序。重复或缺失编号、缺失或非法面积停止处理。
- 不确定代码直接保留，例如 `242`、`410001`、`122`，不加“待核”；已确认的林种用约定的三字简称。
- 林地类型、小班蓄积、经济（竹）林株数、建设内容、工程类别、使用林地性质留空，待外调或资料核定。不将每公顷株数直接当成小班株数。
- 数值零与空白区别保留；坡度为数值角度，以 `°` 显示。备注仅保留塔号以适应固定窄列。
- 固定模板的行高、列宽、字体、边框、合并与数字显示精度不随内容自动调整，全表无背景填充。长树种名称在固定行高中可能显示不全，不擅自缩字或改名，完整值保留在单元格内。

## 验证与交付

脚本在临时目录中用 Excel 保存并正常重新打开，逐单元格核对数据及关键样式后才发布结果。源文件哈希改变、保存或打开失败时停止，不交付未经验证的文件。

交付时简述记录数、面积合计、输出位置和仍需核实的字段。无法运行 Excel 时明确报告未验证，不把 Python 读取或图片预览当作 Excel 正常打开的证据。仅做字段汇整，不声称外业完成或报批就绪。
