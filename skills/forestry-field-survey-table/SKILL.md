# 使用林地外业准备

使用内置 `assets/A.1.xlsx` 作为唯一模板基准。模板包含 35 列“原始因子表”和 24 列“外业调查表”；永久、临时共用同一版式，由显式的 `--use-nature` 区分项目性质。两表均为静态数据，不互相引用；外业填写不自动覆盖原始数据。

## 执行规则

- Windows、桌面 Microsoft Excel、Python 3.10+；无额外 Python 依赖。先读 [字段对应](references/field-mapping.md)。代码字典内置于 `references/code-dictionary.json`，脚本读取同一文件，不依赖网络或个人笔记。
- 输入工作表表头必须从 A1 开始，默认必须存在标准字段 `序号`、`面积`；只忽略表头中的换行、连续空格和首尾空格。字段含义或名称不同即停止并列出差异，不自动把 `小班编号`、`小班编`、`TBMJ`、`XBMJ` 或 `Shape_Area` 当作别名。只有用户明确传入 `--id-field` 或 `--area-field` 时才允许覆盖默认字段。
- `面积` 必须已经确认是占用面积，单位为 hm²。不得从目录名、文件名或其他 GIS 面积字段推断使用性质或占用面积。市、县、乡须来自源表或已确认的参数。
- `--use-nature` 必须显式指定 `临时` 或 `永久`；不从路径、文件名或标题猜测。`使用林地性质` 自动写入模板对应列，并与当前性质保持一致。
- 保留编号及前导零；纯数字编号按数值排序，其余保留源顺序。缺失、重复编号、缺失面积和非法数值停止。可选字段缺失时保留空白并在 warning 中报告。
- 只做已确认的代码转换。未知代码原样保留，不添加“待核”，不按代码前缀猜释；已收录但需源库确认的值单独列入 `dictionary_coverage`。每公顷蓄积仅为数据库参考，不推算或覆盖核定小班蓄积；公益林事权保留原层级，不推断省级、市县级。
- 原始因子表按模板显示标准字段，包括 `使用林地序号`、`株数`、`土层厚度cm` 等。`株数`、小班蓄积、林龄、建设内容、工程类别等按模板和业务规则留空，不把 `MEI_GQ_ZS` 当作外业株数。
- 外业调查表严格按模板的 24 列输出：保留原始地类、林地权属、原优势树种，以及坡向、坡位、坡度、土壤类型、土层厚度的参考列；现状地类、优势树种、龄组、林龄、平均树高、平均胸径、郁闭度、株数和所有实测列留空。不得把原始参考值写入实测列。
- 模板中的字体、字号、颜色、数字格式、合并、边框、填充、列宽、行高、数据验证、条件格式、冻结窗格和工作表视图全部作为资产保留。条件格式只作人工复核提示，不新增或删除业务规则；数据区扩展时保留模板样式。Skill 不主动设置或验收打印区域、分页、PDF 或打印预览。
- 输出只包含 `原始因子表` 和 `外业调查表` 两张工作表，无公式、无外部链接、无额外检查工作表。模板示例数据、项目标题、旧公式结果和绝对路径元数据已清理。

## 运行

```powershell
python "<skill-root>/scripts/forestry_field_survey_table.py" "D:/项目/调查_初表.xls" --use-nature 临时 --project-name "项目全称"
```

标题按“项目全称 使用林地性质 表名”生成。`--project-name` 未提供时使用通用标题“建设项目”，并在 warning 中提醒；不从目录名猜测项目名称。

可选参数：`--project-name`、`--sheet`、`--id-field`、`--area-field`、`--city`、`--county`、`--township`、`--soil-dictionary revision-reference`、`--output`、`--check-only`。多工作表必须指定 `--sheet`；默认编号字段为 `序号`，面积字段为 `面积`。`--check-only` 使用 Excel 和系统临时目录检查，不生成成果。

默认输出源文件同级目录，末尾 `_初表` 换成 `_外调.xlsx`；已有输出拒绝覆盖。源文件先计算 SHA-256，处理和 Excel 重开验证后再次核对，源文件发生变化则停止发布。

交付摘要包含输出位置、记录数、占用面积、warning、`dictionary_version` 和 `dictionary_coverage`。逐格写入通过不等于全部代码释义完成。后续人工整理内业表后，再由 `forestry-survey-summary-tables` 处理报告；本 Skill 不覆盖已经人工完善的工作簿。

旧版字段、旧版表格结构和迁移逻辑不在本 Skill 范围内；发现不匹配时停止并报告。
