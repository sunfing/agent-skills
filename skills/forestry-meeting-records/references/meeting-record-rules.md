# 会议记录规则

## 模板字段

`assets/meeting-record-template.docx` 是不含具体项目、地点或会议事实的单页 Word 模板。双花括号是业务占位符，交付时须全部替换；手写空白使用全角空格，不使用下划线、边框或横线。

| 占位符 | 村级 | 林场 |
| --- | --- | --- |
| `{{meeting_unit}}` | 来源中村名＋`村民委员会`，例如“某某村村民委员会” | 核实的林场全称 |
| `{{project_name}}` | 来源证明中的正式工程名称 | 同左 |
| `{{use_nature}}` | `永久`或`临时`，取对应证明 | 同左 |
| `{{meeting_name}}` | `村民代表大会会议记录` | `会议记录` |
| `{{attendance_subject}}` | 对应村名＋`村民代表`；过长时用“本村村民代表” | `会议人员` |
| `{{discussion_text}}` | 按下述正文结构填写 | 同左，地点和主体对应林场 |
| `{{seal_unit}}` | 对应村名＋`村民委员会` | 核实的林场全称 |

模板标题固定为三段显示在同一标题段落中：

```text
{{meeting_unit}}关于
{{project_name}}
{{use_nature}}使用林地{{meeting_name}}
```

行政区划与会议单位分别记录：例如乡镇名称来自地点，落款使用村委会；不能把完整行政区划直接拼成村委会名称。村名本身以“村”结尾时，“村村民委员会”是正常衔接，不删去其中一个“村”。

## 来源提取

为每份记录保留项目、使用性质、会议主体类型、会议单位、建设单位、地点、地块编号及其字段称谓、面积及单位、对应来源位置。可用临时清单记录，不要求新建正式清单交付物。

- 林木权属证明是数据依据；不同使用性质即使编号相同，也不是同一份记录。
- 正文的“使用林地地块序号”“小班编号”等称谓依来源保留。编号不按新的村级记录顺序重新排列，不把不连续编号压成连续范围。
- 证明已给出该主体对应的总面积时直接采用。需要从多份证明合并或拆分面积时，先确认分组及计算口径，不自动把多个权利主体合成一份会议记录。
- 来源缺失或相互矛盾时，不用零值、旧项目或公示对接备注补齐。已有明确零值不当作缺失，但不能由零值推导“无树”或其他结论。
- 单位、工程名称与地点沿用用户指定证明。发现与用户同时指定的正式名称不一致时，列出差异并确认，不静默替换。

## 讨论正文

沿用已确认的结构，以下中括号只用于解释字段，不能原样留在交付文件中：

```text
会议就〔建设单位〕实施“〔工程名称〕”涉及〔地点〕的〔永久／临时〕使用林地事项进行讨论。涉及〔来源编号字段称谓及编号〕，面积为〔来源面积〕公顷，用于该工程建设。
```

`{{discussion_text}}` 替换为完整正文。核对讨论范围与来源证明相同，避免编号字段本身已有“涉及”而重复拼接。正文不写株数、蓄积或额外权属结论。会议信息不因来源证明已有落款日期或签章而自动填入。

中文与西文、数字之间保留一个半角空格，中文标点用全角；编号连接符内部不加空格，不改变名称或编号本身的语义。面积底层字符串及精度保留，不能将 `0.0122` 改成 `0.01`。

## 页面和填写空间

| 项目 | 当前默认模板 |
| --- | --- |
| 页面 | A4 纵向；上边距 2.3 cm，下边距 2.2 cm，左右各 2.5 cm |
| 标题 | 宋体 16 pt，居中，固定行距 25 pt，段后 18 pt；不加横线或主题色 |
| 正文及填写栏 | 宋体 15 pt，固定行距 26 pt；参会人数及讨论正文首行缩进 30 pt |
| 基本信息 | 时间、地点、主持人、记录人各一行；会议地点保持空白 |
| 日期 | 年份前留四个全角空格，“年”“月”后各两个全角空格，末尾为“日” |
| 人数 | 总人数、应到、实到各留三个全角空格；不要把末尾“人。”挤成独立一行 |
| 签字区 | 正文后显示“参会人员签字：”；模板用段后间距 240 pt 留出较大空白 |
| 落款 | 右下方单位名称＋`（盖章）`，下一行空白日期；村级或林场分别填写 |

每份记录含标题、四行基本信息、参会情况、讨论正文、签字提示、落款及日期，共十个段落。合并时每份标题使用段前分页，避免额外空白页；没有对接封面、页眉或页码。不要将编辑标记、小方块、回车符或软件的拼写提示复制成正文。

这些参数以最终确认的简洁样式为默认，不是所有地区的法定格式。用户提供其他当地模板时按该模板调整。遇到长标题、长编号或较多参会人员，优先调整合理换行、段落间距与签字空间；不要自动增加参会名单、删减编号、缩小字体或改成多页。

## 文件分组与更新

- 村级默认按项目和使用性质合并，各村独立一页，文件名为 `会议记录（永久）.docx` 或 `会议记录（临时）.docx`。同名但不同乡镇的村不得混淆；同村多个权利主体需要先确认会议覆盖方式。
- 林场按每处独立保存为 `会议记录（林场全称）.docx`，放在相同项目、相同使用性质的 `会议记录` 文件夹。
- 不固定项目数量、村数、林场名称或文件数量。多个林场是否合并、其他会议主体及超长内容续页等未确定事项，仅在实际涉及时询问。
- 已存在目标文件且用户未要求覆盖时停止该目标的写入，不自动改名另存。获准更新时比较现有内容，只改授权部分；已填写、签章或人工修改的内容不通过重新填充模板覆盖。
- 来源、原件和未授权文件保留。临时提取数据、备份、页面图像及检查 PDF 均留在系统临时目录；除用户另有要求，只交付对应 DOCX。
