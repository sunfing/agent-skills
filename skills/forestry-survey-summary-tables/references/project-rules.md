# 项目口径

配置只用于当前项目，放在系统临时目录，不写回通用字典或 skill。金额采用公顷×元/平方米＝万元；不把参考测算当作应缴额或实际恢复工程费用。

## 必填项

| 键 | 含义 |
| --- | --- |
| `project_name` | 完整项目名，禁止从旧模板继承 |
| `use_nature` | `临时` 或 `永久`；A.1已有使用性质必须一致 |
| `forest_category_map` | A.1森林类别→本次确认的事权/商品林叶级类别；即便同名也明确列入 |
| `ecology` | `{"mode":"none","confirmed":true}`，或下面的逐区域记录 |
| `fee` | 不适用或逐分类测算，见下 |

`forest_category_map` 目标只能为：`国家级一级公益林`、`国家级二级公益林`、`国家级三级公益林`、`省级公益林`、`市县级公益林`、`重点商品林`、`一般商品林`。同一粗类跨不同事权时，在 `parcel_overrides` 按小班编号逐条指定 `forest_category`，不能统一猜填。

可选 `land_class_map`、`land_type_map`：原文→确认后的标准表列名。不要默认把“其他林地”映射为疏林地，也不要默认把特殊灌木改为一般灌木。默认表1将“薪炭林林地”归入同义的“能源林林地”；其余不同含义须项目确认。

保护等级接受 `1—4`、`I—IV`、`Ⅰ—Ⅳ`；不用于推导公益林保护分级。权属支持 `国有`、`集体`、`个人`；其他权属停止核对。

`parcel_overrides` 为编号→对象，支持 `land_class`、`land_type`、`forest_category`。仅改变报告映射，不修改 A.1。编号必须在 A.1 中存在。

## 重点生态区域

不涉及必须已有项目确认。涉及时提供：

```json
{"mode":"records","records":[{"name":"区域名称","kind":"自然保护区","level":"核实的级别","parcel_ids":["小班编号"]}]}
```

`kind` 限 `自然保护区`、`森林公园`、`湿地公园`、`风景名胜区`。每行对应一个区域；同一小班可涉及多个区域，不跨区域相加作为项目占用总面积。记录必须覆盖 A.1 中所有已标为涉及的小班；“其他区域”等视为不涉及仅在 `none` 已确认或记录中未列入时适用。部分重叠面积不能用整小班代替，先补齐拆分后的 A.1 再生成。

## 附表6

不适用：`{"mode":"not_applicable","basis":"已核实的适用依据"}`。生成保留标题及依据的说明表，不伪造零费用测算。

测算对象：

```json
{
  "mode":"reference",
  "basis":"适用文件及版本",
  "context":"已核实的规划区位置、工程性质、公益林事权及加倍或免征口径",
  "default_multiplier":1,
  "parcel_multipliers":{},
  "categories":[{"name":"收费地类","land_classes":["标准现状地类"],"rate":10}],
  "note":"测算用途及适用限制"
}
```

示意中的数值仅展示 JSON 类型，不是收费默认值；必须依据本项目材料填写。`mode` 可为 `reference`（参考测算）或 `charge`（已确认应缴测算）。临时用林只支持 `reference` 或 `not_applicable`，不自动套用永久用林征收表。

每种现状地类只能匹配一个收费分类，必须覆盖本次全部地类。`rate` 为非负元/平方米；`default_multiplier` 必须明确，按 `parcel_multipliers` 可逐小班调整（含0免征）。程序按面积加权显示“折算单价”，避免同组不同倍数仍写一个原始单价。默认不内置地区单价，不推断城市规划区、公共基础设施或国家/省级公益林倍数。

## 数据检查

要求 A.1 为既定33列表式、标题在第1行、表头第3行、数据从第4行开始，不含小计行。市县乡村、小班编号、占用面积、地类、林地类型、权属、森林类别、保护等级完整；编号不重不空、面积为正且单位公顷。乔木林小班必须有非负核定蓄积，非乔木蓄积不计入报告。

建设内容、工程类别、未译树种代码等不影响汇总时可留空或保留，并在交付中说明。默认33列 A.1 的“经济（竹）林株数”原样传递，不把它重新解释为所有树木株数。
