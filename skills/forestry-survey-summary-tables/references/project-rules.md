# 项目配置

配置保存在系统临时目录，仅适用于本项目。面积单位为公顷，蓄积单位为立方米；公顷 × 元/平方米 ÷ 10000 = 万元。

| 键 | 要求 |
|---|---|
| project_name | 核实的完整项目名，写入现状调查表已有项目名称字段 |
| use_nature | 只能为 临时 或 永久，并与内业表 使用林地性质 一致 |
| forest_map | 将内业森林类别与已确认的统计叶级对应 |
| ecology | none 或逐区域记录，并与内业表 重点生态区域 一致 |
| fee | 河北省恢复费测算条件；永久和临时都必须测算 |
| status_fields | 可选的现状调查表人工文字覆盖 |

## 字段和数值

内业处理表必须严格是当前模板的 36 列，表头第 3 行、数据第 4 行起。字段名称、单位和顺序不一致时停止；只忽略换行、连续空格和首尾空格。旧 37 列、旧字段和旧 A.1 不迁移。

必需市县乡村、唯一的 使用林地序号、正的 面积hm2、现状地类、林地类型、权属、森林类别、保护等级；乔木林必须有非负 小班蓄积m3。已填写的 平均树高m、平均胸径cm、郁闭度(覆盖度)、每公顷蓄积m3、小班蓄积m3、株数、坡度和土层厚度cm 必须为非负数值；郁闭度不得超过 1，株数必须为整数。合理未知值可以留空。

每公顷蓄积m3 是数据库参考值，不参与 小班蓄积m3 的反算或一致性校验。报告蓄积只使用内业核定的 小班蓄积m3，并只统计乔木林。林班号、小班号和使用林地序号的零补位只接受源单元格已经明确设置的数字格式。

## 分类

forest_map 的目标只能是：国家级一级公益林、国家级二级公益林、国家级三级公益林、省级公益林、市县级公益林、重点商品林、一般商品林。内业中重点/一般公益林必须结合国家/地方公益林事权；同一组合存在多个事权时先在内业表填写明确叶级名称，再逐项配置。

保护等级接受 1—4、I—IV 或 Ⅰ—Ⅳ，不从公益林类别推导。林地类型按内业核定值，薪炭林林地在报告中归入能源林林地。现状调查表没有“其他林地/其他无立木林地”栏，遇到这些类别时停止并确认扩展表式。

## 生态区域

不涉及：

```json
{"mode":"none","confirmed":true}
```

涉及时：

```json
{"mode":"records","records":[{"name":"区域名称","kind":"自然保护区","level":"核实级别","parcel_ids":["使用林地序号"]}]}
```

kind 限自然保护区、森林公园、湿地公园、风景名胜区。必须覆盖全部涉及小班；不把不同区域面积加总为项目面积。配置与内业表冲突时停止。

## 河北恢复费测算

永久和临时都必须生成 B.7。临时项目只能使用：

```json
{"mode":"reference","region":"河北省","urban_planning_area":false,"project_kind":"公共基础设施"}
```

永久项目可使用 reference 或 charge。project_kind 限公共基础设施、公共事业、国防、经营性；其他地区停止并要求新的标准。

10 元类：郁闭度不低于 0.2 的乔木林地、竹林地、苗圃地、采伐迹地、火烧迹地。6 元类：国家特别规定灌木林地、一般灌木林地、疏林地、未成林造林地。低于 0.2 的乔木林等未覆盖情况显示“待核定”。国家级、省级公益林加倍；城市规划区内加倍；规划区外经营性项目加倍。

B.7 保留财税〔2015〕122号、冀财税〔2016〕25号和参考用途说明。临时项目追加“临时使用林地不再收取森林植被恢复费，实际恢复工程费用另计”的政策说明；永久项目追加异地恢复说明。fee.mode 不允许 not_applicable，因为两种项目性质都需要植被恢复测算。

## 现状调查表人工项

允许 status_fields 指定：M3、D4、M4、R4 以及 A14、A15、A20、A22、A24、A26、A28、A30、A34。具体含义按模板相邻标题核对，不猜批复、生态结论或签字。现状调查表的面积总计从第 8 行开始，蓄积总计从第 11 行开始；项目名称和恢复费显示由脚本生成。
