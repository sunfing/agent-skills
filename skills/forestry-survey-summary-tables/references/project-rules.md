# 项目配置

配置保存在系统临时目录，仅适用于本项目。面积单位公顷，蓄积立方米；公顷×元/平方米＝万元。

| 键 | 要求 |
|---|---|
| `project_name` | 核实的完整项目名，用于所有生成报告的标题 |
| `use_nature` | `临时`或`永久`，不得与内业表冲突 |
| `forest_map` | A.1组合森林类别→已确认统计叶级；普通/重点商品林自带同名映射 |
| `ecology` | 确认不涉及，或逐区域记录 |
| `fee` | 河北测算条件，或不适用依据 |
| `status_fields` | 可选现状调查表人工文字，覆盖原表同单元格 |

## 分类和数据

内业处理表：表头第3行，数据第4行开始，不含小计。必需市县乡村、唯一编号、正占用面积、现状地类、林地类型、权属、森林类别及保护等级；乔木林须有非负核定小班蓄积。现有表式支持国有、集体，个人权属须先扩展表式，不能丢弃。

内业“重点/一般公益林”结合“国家公益林/地方公益林”，在A.1显示“重点/一般国家公益林”“重点/一般地方公益林”。`forest_map`目标仅允许：国家级一级、二级、三级公益林，省级公益林、市县级公益林、重点商品林、一般商品林（均写全称）。同一组合含多个事权时，先在内业森林类别中填写明确叶级名称，配置同名映射；不得用统一映射掩盖差异。

保护等级接受1—4、I—IV、Ⅰ—Ⅳ，不推导公益林分级。林地类型按内业核定值，薪炭林林地在报告归入能源林林地。现状表未含“其他林地/其他无立木林地”栏，涉及则停止，先确认扩展表式。

B.5按项目和县统计，基础含乔木、竹、特殊灌木、一般灌木、疏林，其他支持地类在涉及时补列。新增地类须重跑。非乔木蓄积始终排除；每公顷蓄积仅参考。

## 生态区域

不涉及：`{"mode":"none","confirmed":true}`；内业必须无涉及记录。

涉及时：
```json
{"mode":"records","records":[{"name":"区域名称","kind":"自然保护区","level":"核实级别","parcel_ids":["编号"]}]}
```
`kind`限自然保护区、森林公园、湿地公园、风景名胜区。需覆盖全部涉及小班；可跨区域重复，不把不同区域加总为项目面积。部分重叠须先拆分小班，不用整小班代替。

## 河北费用模板

模板B.7含财税〔2015〕122号、冀财税〔2016〕25号及10/6元两类基础单价；宜林地3元规则记录于依据，但本版未纳入宜林地输入与表列。

```json
{"mode":"reference","region":"河北省","urban_planning_area":false,"project_kind":"公共基础设施"}
```

上述规划区位置及项目性质是示例，必须逐项目核实。`project_kind`限公共基础设施、公共事业、国防、经营性；`mode`为reference或charge，临时用林禁止charge。其他地区停止并要求新标准，不自动套用河北。

10元类：实际郁闭度≥0.2的乔木林地、竹林地、苗圃地、采伐迹地、火烧迹地。6元类：灌木、疏林、未成林造林地。低于0.2的乔木林等未覆盖情况显示“待核定”，不猜单价。

国家级、省级公益林加倍；城市规划区内加倍，规划区外经营性项目加倍。I8、L8为两类基础单价控制格，其他行引用它们；金额另计公益林及项目倍数，并在表下注明。不得把基础单价误认为含倍数单价。

临时使用林地不再收取森林植被恢复费（国家林草局2023年第13号公告），参考测算不代表应缴额，实际恢复工程费用另计。不适用可用 `{"mode":"not_applicable","basis":"已核实依据"}`。

## 现状表人工项

允许 `status_fields` 指定：M3项目类型、D4审批机关、M4文号、R4日期，以及A14、A15、A20、A22、A24、A26、A28、A30、A34文字栏。具体含义按模板相邻标题核对，不猜批复、生态结论或签字。原表这些静态值默认保留，配置优先；公式不复制。D3项目名与A13费用由脚本生成。
