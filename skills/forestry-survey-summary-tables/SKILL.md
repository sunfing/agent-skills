# 使用林地报告附表 B.1—B.7 及小班明细

使用内置 `assets/report-headers.xlsx`，按 B.1—B.7、小班明细顺序组织表式；沿用已确认模板的原有表头，补齐 B.5 交叉表，清除项目数据。B.7 读取模板的基础版式、字体、行高和列宽，再按项目配置调整收费分类、单价和必要列数，不沿用模板中的分类作为项目结论。Windows、桌面 Microsoft Excel、Python 3.10+，不需额外 Python 包。

## 执行边界

- 从源工作簿 `A.1` 的33列读取数据，默认在同一文件生成 B.1—B.7 和“小班明细”，保留 A.1 和其他工作表。已有旧版1—7或新版报告表时，只有用户授权重建才加 `--replace-sheets`；重建会移除旧版报告表并生成新版全套，避免混留编号。
- 升级对应：旧1—4→B.1—B.4，旧5→B.6，旧6→B.7，旧7→小班明细，新增 B.5。模板、公式、打印文件同步更新，不能只重命名标签。
- 先讨论、检查可行性时只读取，不运行会创建暂存文件的命令。
- 不替用户核定外业、权属、公益林事权或收费政策。先读 [项目口径](references/project-rules.md)，将本项目已确认的内容写入系统临时目录的 JSON；缺少必要口径时只询问对应项，不复用上个项目。
- B.1—B.4：林地类型、现状地类、森林类别、保护等级的面积与蓄积；B.5：分森林类别按地类和权属统计面积；B.6：重点生态区域；B.7：恢复费测算或不适用说明；“小班明细”：28列报告版明细，不占 B 系列编号。B.8 拐点坐标表由另一个工作流程提供，不生成或改动。
- 蓄积仅计乔木林地，直接使用核定“小班蓄积”；每公顷蓄积仅保留参考，不反算。零值显示为空白，原始零与空白仍区分。
- 未知优势树种等非汇总字段保留代码。影响统计的未知地类、林地类型、森林类别、保护等级必须明确映射，不能用0代替未核定。

## 生成与交付

先暂存（打印路径中的文件都在系统临时目录）：

```powershell
python "<skill-root>/scripts/summary_tables.py" "D:/项目/使用林地小班因子调查表.xlsx" --config "<temp>/project-rules.json"
```

可选 `--output`（另存）、`--replace-sheets`（明确重建）、`--stage-dir`（必须是新建的空暂存目录）。默认不会立即覆盖原文件。程序验证数据、生成表格、用 Excel 正常保存重开、核对全部单元格及小计，并输出 `stage.json`、`candidate.xlsx` 和8份打印 PDF。

逐张渲染查看 PDF：表头、行政区合并、换行、数字、页边距、重复表头和跨页是否完整。28列明细采用横向 A4；行政区较多时允许多页，不强压一页。若出现截字或过小字体，调整暂存任务的排版后重新生成并校验；不能跳过审阅就发布。

检查通过后，同一任务原有授权足以执行：

```powershell
python "<skill-root>/scripts/summary_tables.py" --publish-stage "<stage-dir>/stage.json"
```

发布前复核源文件和候选文件哈希；任一发生变化即停止。另存不覆盖既有文件。源文件被 Excel 占用时保留暂存结果，提示用户关闭文件再重试，不关闭用户 Excel 或强行解锁。

## 版式与复用

- 宋体、白底、细边框；B.1—B.4 纵向 A4，B.5—B.7 及小班明细横向 A4；设置打印范围、重复表头及分页预览。“第1页”是预览标识，不是打印水印。
- 汇总层级来自实际市、县、乡、村，编号与前导零不变。省总计、各级小计只汇总下级，不能把小计再次计入总计。
- 数据通过公式连接 A.1；面积和蓄积改值可重算。新增、删除、排序小班或修改分类、行政区及项目口径后须重新生成，不能把本次分组当作动态分类数据库。
- 不加审计工作表、长期项目配置或额外输出；预览和验证材料留在临时目录。交付只说明正式文件位置、记录数、面积、蓄积、空缺项及实际完成的打印检查，不声称报批已通过。

安装或更新时完整复制本 skill 文件夹，保留 `assets`、`scripts`、`references` 与 `agents` 的相对位置。不依赖另一个 skill 的代码或本机项目路径。
