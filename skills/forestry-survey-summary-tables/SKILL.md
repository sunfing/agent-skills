# 使用林地联动报告表

以 `assets/report-headers.xlsx` 为唯一版式底座，由脚本生成本项目公式。需要 Windows、桌面 Microsoft Excel、Python 3.10+，不需额外 Python 包。

## 数据流与输入边界

固定顺序：原始因子表 → 外业调查表 → 内业处理表 → 现状调查表 → A.1 → B.1—B.7。只有 `内业处理表` 是报告数据源；前两张输入表按用户工作簿中的实际状态保留，不用它们替代内业核定结果。

`内业处理表` 必须严格使用当前模板的 36 个字段，表头位于第 3 行、数据从第 4 行开始，字段顺序为：

`市`、`县`、`乡`、`村`、`林班号(村小组)`、`小班号林地落界`、`使用林地序号`、`面积hm2`、`原始地类`、`现状地类`、`林地类型`、`林地权属`、`森林类别`、`公益林事权`、`林地保护等级`、`林种`、`起源`、`重点生态区域`、`优势树种`、`龄组(产期)`、`林龄`、`平均树高m`、`平均胸径cm`、`郁闭度(覆盖度)`、`每公顷蓄积m3`、`小班蓄积m3`、`株数`、`坡向`、`坡位`、`坡度`、`土壤类型`、`土层厚度cm`、`建设内容`、`工程类别`、`使用林地性质`、`备注`。

表头只忽略换行、连续空格和首尾空格；字段名称、标点、单位和字段顺序必须一致。发现缺失、增加、改名或错位字段时直接停止并报告差异，不兼容旧版 37 列、旧字段或旧 A.1，也不自动迁移。

`use_nature` 只能为 `永久` 或 `临时`，用于一致性检查和说明文字。两种性质共用相同字段、报告结构和公式；两种性质都必须生成植被恢复测算。永久使用林地的说明使用异地恢复语义，临时使用林地保留临时政策说明。临时项目只允许 `fee.mode=reference`，永久项目可按配置使用 `reference` 或 `charge`。

## 分类、数值和业务边界

- 必须核实市县乡村、唯一的 `使用林地序号`、正的 `面积hm2`、现状地类、林地类型、权属、森林类别、保护等级和乔木林 `小班蓄积m3`。
- 已填写的 `平均树高m`、`平均胸径cm`、`郁闭度(覆盖度)`、`每公顷蓄积m3`、`小班蓄积m3`、`株数`、`坡度`和`土层厚度cm`必须是非负数值；郁闭度必须在 0—1 内，`株数`必须为整数。允许合理空白，不把百分数自动转换为比例。
- `每公顷蓄积m3`仅为数据库参考值，绝不反算或校验 `小班蓄积m3`；报告蓄积只使用内业核定的 `小班蓄积m3`，且只统计乔木林。
- 保留数字编号源单元格中的明确零补位格式；不根据项目习惯猜位数。未知代码和未确认的跨字段关系保留原值并使用核查提示。
- `森林类别`、`公益林事权`、`林地类型`、`林种`、树种与龄组、坡向坡位坡度等关系需要人工核定；不凭公式猜测。
- 现状调查表没有“其他林地/其他无立木林地”栏，遇到这些类别时停止并要求确认扩展表式。

## 输出和格式验收

生成并同名重建 `现状调查表`、`A.1`、`B.1`—`B.7`（包括 `B.5`），保留其他工作表。报告表结构以模板为准：`现状调查表` 38 行、`A.1` 29 列、`B.5` 固定为 `A1:O1` 标题、`A2:O2` 单位行、数据从第 6 行开始，`B.7` 明细从第 7 行开始。现状调查表续表 1—7 的人工填写正文留空，正文区域和编制单位意见区域统一水平左对齐、垂直居中；B.7 第 22—29 行保留八行空白合并区域，供人工填写。

`A.1` 的 `重点生态区域` 对无涉项目直接留空；`B.6` 仅在汇总结论单元格显示“不涉及”。`B.5` 严格使用当前模板的 15 列和五个现状地类列，输入出现模板没有的地类时停止并报告，不扩展列数。

模板资产只保留结构、样式和校验规则，不携带项目示例数据。输入表在报告重建后按源工作簿实际状态原样保留；源表已经缺失的格式不自行猜测恢复。生成的报告工作表不携带字体颜色，字体名称、字号、粗体、斜体、数字格式、合并单元格、边框、填充、列宽、行高、数据验证、条件格式、冻结窗格和工作表视图按模板处理。B.7 的恢复费测算逻辑仍按配置执行，第 22—29 行不自动写入政策说明。

不执行打印区域、分页符、纸张、页边距、打印预览、PDF 或打印版式检查，也不为这些检查增加额外处理步骤。

## 处理与校验

项目配置放系统临时目录，不提交到通用 Skill：

```powershell
python "<skill-root>/scripts/summary_tables.py" "D:/项目/调查表.xlsx" --config "<temp>/project-rules.json"
```

命令先在系统临时目录生成候选文件，核对工作表结构、输入表保留、模板格式与校验规则、公式和独立小计，再通过 Excel 只读重开核对显示与计算结果，成功后才原地替换。源文件在处理期间变化或被占用时停止，不覆盖用户的新修改，也不强关用户 Excel。

## 配置和升级

先读 [项目配置](references/project-rules.md)。`project_name`、`use_nature`、`forest_map`、`ecology`、`fee` 和可选 `status_fields` 必须按项目核实。河北标准只用于河北项目；其他地区停止并要求新的标准。

完整同步本 Skill 文件夹。旧 37 列输入、旧字段、旧 A.1 或旧配置不做静默迁移；需要迁移时先人工整理到当前模板，再运行本 Skill。 `--replace-sheets` 仅保留命令兼容，同名报告始终重建。
