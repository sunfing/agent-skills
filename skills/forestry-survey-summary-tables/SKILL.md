# 使用林地联动报告表

以 `assets/report-headers.xlsx` 为版式底座，由脚本生成本项目公式，不沿用模板样例范围。需要 Windows、桌面 Microsoft Excel、Python 3.10+，不需额外 Python 包。

## 数据流与边界

固定顺序：原始因子表 → 外业调查表 → 内业处理表 → 现状调查表 → A.1 → B.1—B.7。外业表采用22列精简表式，内业表仍为37列；前两张若不存在不伪造；其他工作表保留在后。原始因子表和外业调查表独立，内业处理表须人工核定；只有内业处理表是报告数据源。

- 标准内业表37列，表头第3行、数据第4行起；按表头定位，兼容额外“旧编号”，不将其写入报告。模板自带空白输入表供人工使用，脚本不推定外业结果。
- A.1为28列报告明细，含逐级小计，取代旧“小班明细”。B.1—B.4为林地类型、现状地类、森林类别、保护等级面积与蓄积；B.5为森林类别×地类×权属；B.6为生态区域；B.7为费用。现状调查表引用A.1和B.7，审批与文字信息另行核定。
- 已有记录的面积、核定蓄积、地类、林地类型、权属、保护等级和已配置森林类别修改后，公式自动重算并重新归类。面积或乔木蓄积被清空/变成非法值时显示公式错误，避免静默少计。
- 增删或排序小班、行政区分组改变、新增未配置类别、生态区域范围或收费条件改变时，必须重跑。B.5按生成时涉及地类扩列，新地类即使其他表能计算也须重建。
- 仅计乔木林核定小班蓄积；非乔木蓄积不改输入，但不计报告。每公顷蓄积不反算，显示2位小数；面积显示4位，树高、胸径、郁闭度及小班蓄积显示1位，株数显示整数。数值零隐藏，编号零不隐藏，底层值与空白仍区分。阈值按底层实际值计算；郁闭度须在0—1内，不自动把百分数换算为比例。株数须为非负整数。数字编号保留源单元格明确的纯零补位格式，文本编号原样引用。
- 先读 [项目配置](references/project-rules.md)。不把其他林地自动改疏林地，不把地方公益林统一推为市县级，不把BH_DJ当公益林保护分级。未知非统计代码原样保留。
- 正式表不写“按用户确认”等沟通记录。B.7保留政策、条件和参考用途；河北基准内置，其他地区停止并要求新的标准。临时用林仅参考，不写成应缴额。
- 现状调查表（含续表）、A.1及B.1—B.7沿用版式模板中的标题文本和报告表号，不自动追加 `project_name` 或 `use_nature`。项目名称、项目性质等数据只写入模板已有的对应字段；不改输入表标题。
- 按模板标题、表头、明细和说明行分别取样式，不用通用数字格式覆盖正文。B.7说明左对齐换行；B.5扩展列继承表内对齐与换行规则。保留模板手动分页和重复打印表头，现状调查续表从第16行另起一页。B.5扩列时适配一页宽、长度自然分页，其余表保留模板缩放。横向合并文字按实际字体和宽度测量，只增加必要行高；单行超出Excel可打印行高时停止，要求核定拆分内容。行政区和面积/蓄积标签跨页时分段合并并重复标识，不为凑页数提前分页。打印PDF仍须逐页审阅，B.8由拐点 Skill处理。
- 前 3 张输入表（`原始因子表`、`外业调查表`、`内业处理表`）保持源文件的内容、样式与布局，不统一指定字号。Excel 跨工作簿复制后保存可能使输入表标题字体回退；脚本在保存后的候选包中恢复源文件 `A1` 及其合并区域各单元格的字体，克隆独立样式，不改共用样式或公式缓存。保留校验覆盖单元格值、公式、样式、合并、行列布局、分页、打印区域、重复打印标题、页眉页脚及工作表隐藏状态；报告另校验字段数字格式、说明对齐和打印设置。Excel只读重开核对字体、公式、小计、编号/株数显示及跨页标签，通过后才导出PDF并生成发布清单。若源文件本身已丢失格式，须另行核定恢复依据。
- “先讨论”只读取；已有报告仅在用户授权后用 `--replace-sheets` 重建。前3张输入表不改动，旧1—7及小班明细移除；报告中的手工数字会重建，现状表允许的人工文字单元格保留，可用配置覆盖。

## 生成、验证、发布

项目配置放系统临时目录，不提交到通用 Skill：

```powershell
python "<skill-root>/scripts/summary_tables.py" "D:/项目/调查表.xlsx" --config "<temp>/project-rules.json" --replace-sheets
```

可选 `--output` 另存、`--stage-dir` 指定新暂存目录。默认只暂存，不立即改源文件。生成 `candidate.xlsx`、9份打印PDF、`stage.json`；通过 Excel 保存重开、逐公式与独立小计验证，并核对输入表数据、样式及布局未变。

逐表审阅PDF的表头、数字、列宽和截字。检查通过后，在原有授权范围内发布：

```powershell
python "<skill-root>/scripts/summary_tables.py" --publish-stage "<stage-dir>/stage.json"
```

发布再次校验源文件及候选哈希，变化即停止。源文件被占用时提示用户保存关闭，不强关Excel。另存不覆盖已有文件。交付报告实际验证、记录数、面积、蓄积及待完善事项，不声称已达到报批条件。

Excel在独立的隐藏实例中运行，记录本次实例的进程ID与启动时间；先释放单元格等COM引用再关闭工作簿和退出，异常退出停止发布。正常结束、报错或超时均核对退出，必要时只终止PID及启动时间匹配本次记录的实例和可追溯的子进程，不按进程名称批量关闭。不得接管或关闭用户原有Excel。测试使用系统临时目录副本，结束时检查实例退出；测试项通过、打印人工审阅与未验证事项分别报告，不能以CI通过代替实际打印验收。

Excel复制后的固定表头及现状调查表边框、各报告单元格底色也在保存后按模板恢复并逐格比对，避免表框线丢失或带入源表底色；B.5动态表头按实际扩列重建，不套用固定列数的边框。
