# 使用林地联动报告表

以 `assets/report-headers.xlsx` 为版式底座，由脚本生成本项目公式，不沿用模板样例范围。需要 Windows、桌面 Microsoft Excel、Python 3.10+，不需额外 Python 包。

## 数据流与边界

固定顺序：原始因子表 → 外业调查表 → 内业处理表 → 现状调查表 → A.1 → B.1—B.7。外业表采用22列精简表式，内业表仍为37列；前两张若不存在不伪造；其他工作表保留在后。原始因子表和外业调查表独立，内业处理表须人工核定；只有内业处理表是报告数据源。

- 标准内业表37列，表头第3行、数据第4行起；按表头定位，兼容额外“旧编号”，不将其写入报告。模板自带空白输入表供人工使用，脚本不推定外业结果。
- A.1为28列报告明细，含逐级小计，取代旧“小班明细”。B.1—B.4为林地类型、现状地类、森林类别、保护等级面积与蓄积；B.5为森林类别×地类×权属；B.6为生态区域；B.7为费用。现状调查表引用A.1和B.7，审批与文字信息另行核定。
- 已有记录的面积、核定蓄积、地类、林地类型、权属、保护等级和已配置森林类别修改后，公式自动重算并重新归类。面积或乔木蓄积被清空/变成非法值时显示公式错误，避免静默少计。
- 增删或排序小班、行政区分组改变、新增未配置类别、生态区域范围或收费条件改变时，必须重跑。B.5按生成时涉及地类扩列，新地类即使其他表能计算也须重建。
- 仅计乔木林核定小班蓄积；非乔木蓄积不改输入，但不计报告。每公顷蓄积不反算，显示2位小数；面积显示4位，树高、胸径、郁闭度及小班蓄积显示1位，株数显示整数。数值零隐藏，编号零不隐藏，底层值与空白仍区分。阈值按底层实际值计算；郁闭度须在0—1内，不自动把百分数换算为比例。株数须为非负整数。数字编号保留源单元格明确的纯零补位格式，文本编号原样引用。
- 先读 [项目配置](references/project-rules.md)。不把其他林地自动改疏林地，不把地方公益林统一推为市县级，不把BH_DJ当公益林保护分级。未知非统计代码原样保留。
- 正式表不写“按用户确认”等沟通记录。B.7保留政策、条件和参考用途；河北基准内置，其他地区停止并要求新的标准。临时用林仅参考，不写成应缴额。
- 现状调查表（含续表）、A.1及B.1—B.7沿用版式模板中的标题文本和报告表号，不自动追加 `project_name` 或 `use_nature`。项目名称、项目性质等数据只写入模板已有的对应字段；不改输入表标题。
- 保留模板字段、标题、合并、边框、列宽和基础行高。B.7说明左对齐换行，B.5扩展列继承正文对齐。不自动追加项目名或用地性质，不缩小字号、不按页拆分合并区域。报告字体（包括颜色）、底色及固定表头边框按模板恢复并核对，避免跨工作簿样式污染。
- `原始因子表`、`外业调查表`、`内业处理表`按输入文件的实际状态原样保留。这是本 Skill 的固定边界，不是某个项目的历史特例。其他非目标工作表也保留。源表本身已经丢失的格式不能自行猜测恢复。
- 只清除新生成报告表的打印区域、重复打印标题、页面设置、页边距、页眉页脚和手动分页符，使用普通工作表视图。不生成PDF、不做打印预览、不进行打印排版验收；不测量逐格文本高度，也不根据纸张分页拆分表格。Excel自己显示的默认纸张参数不代表Skill配置了打印格式。
- 用户要求处理指定工作簿时，默认在原路径更新：同名`现状调查表`、`A.1`、`B.1—B.7`（包括B.5）直接重建，不另交付`_报告表.xlsx`。旧1—7及小班明细按现有迁移规则移除。报告内手填数字会重建；现状表允许的静态人工文字保留，显式项目配置可覆盖。
- “先讨论”只读取，不运行生成或覆盖。执行授权后由同一命令完成临时生成、校验和原地替换，不另设人工发布步骤。

## 处理与校验

项目配置放系统临时目录，不提交到通用 Skill：

```powershell
python "<skill-root>/scripts/summary_tables.py" "D:/项目/调查表.xlsx" --config "<temp>/project-rules.json"
```

内部先在系统临时目录生成安全副本，核对工作表结构、输入表保留、报告字体颜色和数值格式、公式及独立小计，再通过Excel只读重开核对显示与计算结果，成功后原地替换用户指定文件。源文件在处理期间发生变化或被占用则停止，不覆盖用户的新修改、不强关用户Excel。失败不发布候选文件。

Excel使用独立隐藏实例，保留本次进程身份记录；正常结束或异常时释放引用并退出，仅清理可证明属于本次任务的实例。不要打开可见测试工作簿或接管用户会话。

验收使用系统临时目录副本，覆盖首次生成、同名报告重建、公式联动及输入表保护。检查报告未存储自定义打印设置属于文件结构检查，不进行打印渲染。交付只报告原文件更新位置、记录数、面积、蓄积和缺失信息，不声称达到报批条件。

## 升级

完整同步本 Skill 文件夹。新版单次命令自动校验并原地更新，移除旧`--output`、`--stage-dir`和`--publish-stage`入口；`--replace-sheets`仅保留命令兼容，同名报告始终重建。旧配置 `forest_category_map`、`parcel_overrides`、逐项目 `fee.categories` 不再适用；按项目配置重新确认。旧33列A.1须先人工整理到新内业表，不能直接换表名冒充升级。模板只提供版式和河北标准，不携带任何项目数据或上次口径。
