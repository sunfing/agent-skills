# 使用林地联动报告表

以 `assets/report-headers.xlsx` 为版式底座，由脚本生成本项目公式，不沿用模板样例范围。需要 Windows、桌面 Microsoft Excel、Python 3.10+，不需额外 Python 包。

## 数据流与边界

固定顺序：原始因子表 → 外业调查表 → 内业处理表 → 现状调查表 → A.1 → B.1—B.7。前两张若不存在不伪造；其他工作表保留在后。原始因子表和外业调查表独立，内业处理表须人工核定；只有内业处理表是报告数据源。

- 标准内业表37列，表头第3行、数据第4行起；按表头定位，兼容额外“旧编号”，不将其写入报告。模板自带空白输入表供人工使用，脚本不推定外业结果。
- A.1为28列报告明细，含逐级小计，取代旧“小班明细”。B.1—B.4为林地类型、现状地类、森林类别、保护等级面积与蓄积；B.5为森林类别×地类×权属；B.6为生态区域；B.7为费用。现状调查表引用A.1和B.7，审批与文字信息另行核定。
- 已有记录的面积、核定蓄积、地类、林地类型、权属、保护等级和已配置森林类别修改后，公式自动重算并重新归类。面积或乔木蓄积被清空/变成非法值时显示公式错误，避免静默少计。
- 增删或排序小班、行政区分组改变、新增未配置类别、生态区域范围或收费条件改变时，必须重跑。B.5按生成时涉及地类扩列，新地类即使其他表能计算也须重建。
- 仅计乔木林核定小班蓄积；非乔木蓄积不改输入，但不计报告。每公顷蓄积不反算。郁闭度显示1位小数，阈值按底层实际值计算；零值隐藏显示，底层零与空白仍区分。
- 先读 [项目配置](references/project-rules.md)。不把其他林地自动改疏林地，不把地方公益林统一推为市县级，不把BH_DJ当公益林保护分级。未知非统计代码原样保留。
- 正式表不写“按用户确认”等沟通记录。B.7保留政策、条件和参考用途；河北基准内置，其他地区停止并要求新的标准。临时用林仅参考，不写成应缴额。
- 保留模板版式和打印设置，只扩展打印范围。自动续页、手动分页及跨页合并优化暂不实现，打印PDF仍须审阅。B.8由拐点 Skill处理。
- “先讨论”只读取；已有报告仅在用户授权后用 `--replace-sheets` 重建。前3张输入表不改动，旧1—7及小班明细移除；报告中的手工数字会重建，现状表允许的人工文字单元格保留，可用配置覆盖。

## 生成、验证、发布

项目配置放系统临时目录，不提交到通用 Skill：

```powershell
python "<skill-root>/scripts/summary_tables.py" "D:/项目/调查表.xlsx" --config "<temp>/project-rules.json" --replace-sheets
```

可选 `--output` 另存、`--stage-dir` 指定新暂存目录。默认只暂存，不立即改源文件。生成 `candidate.xlsx`、9份打印PDF、`stage.json`；通过 Excel 保存重开、逐公式与独立小计验证，并核对输入表数据、样式及布局未变。

逐表审阅PDF的表头、数字、列宽和截字。检查通过后，在原有授权范围内发布：

```powershell
python "<skill-root>/scripts/summary_tables.py" --publish-stage "<stage-dir>/stage.json"
```

发布再次校验源文件及候选哈希，变化即停止。源文件被占用时提示用户保存关闭，不强关Excel。另存不覆盖已有文件。交付报告实际验证、记录数、面积、蓄积及待完善事项，不声称已达到报批条件。
